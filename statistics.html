1. Introduction

Statistics is the branch of mathematics that deals with the collection, organisation, presentation, analysis and interpretation of data.

In Class 10, we mainly study the mean, median and mode of grouped data.

2. Important Terms

Data

A collection of information or observations is called data.

Frequency

The number of times an observation occurs is called its frequency.

Class Interval

A range such as 10–20, 20–30, 30–40 is called a class interval.

Class Size

Class Size = Upper Class Limit − Lower Class Limit

Class Mark

Class Mark = (Upper Class Limit + Lower Class Limit) / 2

3. Grouped Data

When data is arranged into class intervals along with their frequencies, it is called grouped data.

Class Interval Frequency (f)
0–10 5
10–20 8
20–30 12
30–40 7

4. Mean of Grouped Data

The mean represents the average value of the observations.

Method 1 – Direct Method

Mean = Σfᵢxᵢ / Σfᵢ

where:
fᵢ = frequency
xᵢ = class mark

Steps

  1. Find the class mark xᵢ.
  2. Multiply fᵢ by xᵢ.
  3. Find Σfᵢxᵢ.
  4. Find Σfᵢ.
  5. Use Mean = Σfᵢxᵢ / Σfᵢ.
Example:

Class intervals: 0–10, 10–20, 20–30
Frequencies: 2, 3, 5

Class marks:
5, 15, 25

Σfᵢxᵢ
= 2×5 + 3×15 + 5×25
= 10 + 45 + 125
= 180

Σfᵢ = 2 + 3 + 5 = 10

Mean = 180/10
= 18

5. Assumed Mean Method

The assumed mean method makes calculations easier when class marks are large.

dᵢ = xᵢ − a

Mean = a + Σfᵢdᵢ / Σfᵢ

Here a is the assumed mean.

Example:

Suppose the class marks are 15, 25 and 35. Choose:
a = 25

Then:
dᵢ = xᵢ − 25

The values become:
−10, 0, 10

Now use:
Mean = a + Σfᵢdᵢ / Σfᵢ

6. Step-Deviation Method

The step-deviation method is useful when class intervals have equal size and the deviations can be simplified.

uᵢ = (xᵢ − a) / h

Mean = a + h(Σfᵢuᵢ / Σfᵢ)

Here:
a = assumed mean
h = class size
xᵢ = class mark

7. Median of Grouped Data

The median is the middle value of the data after arranging it in order. For grouped data, we use the median formula.

Median = l + [(n/2 − cf) / f] × h

Where:

  • l = lower boundary of median class
  • n = total frequency
  • cf = cumulative frequency before median class
  • f = frequency of median class
  • h = class size

How to Find Median

  1. Find total frequency n.
  2. Calculate n/2.
  3. Find cumulative frequencies.
  4. Identify the median class.
  5. Use the median formula.
Example:

Suppose:
n = 50
n/2 = 25

The class whose cumulative frequency first becomes equal to or greater than 25 is the median class.

8. Mode of Grouped Data

Mode is the value that occurs most frequently. For grouped data, the modal class is the class with the highest frequency.

Mode = l + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × h

Where:

  • l = lower boundary of modal class
  • f₁ = frequency of modal class
  • f₀ = frequency of class before modal class
  • f₂ = frequency of class after modal class
  • h = class size
Example:

If the highest frequency is 18 in the class interval 20–30, then 20–30 is the modal class.

9. Cumulative Frequency

Cumulative frequency is obtained by continuously adding the frequencies.

Class Frequency Cumulative Frequency
0–10 5 5
10–20 8 13
20–30 12 25
30–40 7 32
To get cumulative frequency, keep adding the frequencies from the first class onwards.

10. Median Class

The median class is the class whose cumulative frequency is just greater than or equal to n/2.

Median Class → First class where CF ≥ n/2

11. Empirical Relation

For a moderately symmetrical distribution, the following empirical relationship is used:

Mode = 3 Median − 2 Mean

or

3 Median = Mode + 2 Mean
Example:

Mean = 20
Median = 22

Mode = 3(22) − 2(20)
= 66 − 40
= 26

12. Continuous Class Intervals

Sometimes class intervals are written in a form such as:

10–19, 20–29, 30–39

To convert them into continuous intervals, we may use the correction factor when required.

For example:

10–19, 20–29

can be converted to:
9.5–19.5, 19.5–29.5

14. Solved Example – Mean

Question:
Find the mean of the following data.

| x | 10 | 20 | 30 |
| f | 2 | 3 | 5 |

Solution:

Σfx = 2×10 + 3×20 + 5×30
= 20 + 60 + 150
= 230

Σf = 2 + 3 + 5 = 10

Mean = Σfx/Σf
= 230/10
= 23

15. Solved Example – Median

Question:
For a grouped distribution, total frequency is 40. The median class has:

l = 20
cf = 15
f = 10
h = 10

Find the median.

Solution:
Median = l + [(n/2 − cf)/f] × h

= 20 + [(40/2 − 15)/10] × 10
= 20 + [(20 − 15)/10] × 10
= 20 + 5
= 25

16. Solved Example – Mode

Question:
For a distribution:

l = 20
f₁ = 18
f₀ = 12
f₂ = 10
h = 10

Find the mode.

Solution:
Mode = l + [(f₁−f₀)/(2f₁−f₀−f₂)] × h

= 20 + [(18−12)/(36−12−10)] × 10
= 20 + (6/14) × 10
≈ 24.29

17. Common Mistakes

  • Class mark निकालना न भूलें।
  • Total frequency n सही निकालें।
  • Median class गलत न चुनें।
  • Median formula में cf median class से पहले वाली cumulative frequency होती है।
  • Mode में f₀, f₁ और f₂ की position ध्यान से देखें।
  • Formula में h यानी class size सही रखें।
  • Calculation के बाद answer दोबारा check करें।

1. परिचय

सांख्यिकी गणित की वह शाखा है जिसमें आँकड़ों का संग्रह, व्यवस्थित करना, प्रस्तुतीकरण, विश्लेषण और व्याख्या की जाती है।

कक्षा 10 में मुख्य रूप से grouped data का Mean, Median और Mode पढ़ा जाता है।

2. महत्वपूर्ण शब्द

आँकड़े (Data)

सूचनाओं या observations के संग्रह को आँकड़े कहते हैं।

आवृत्ति (Frequency)

कोई observation जितनी बार आता है, उसे उसकी आवृत्ति कहते हैं।

वर्ग-अंतराल (Class Interval)

10–20, 20–30, 30–40 जैसे अंतराल को वर्ग-अंतराल कहते हैं।

वर्ग-चिह्न (Class Mark)

Class Mark = (ऊपरी सीमा + निचली सीमा) / 2

3. Grouped Data

जब आँकड़ों को class intervals और frequencies के साथ व्यवस्थित किया जाता है, तो उसे grouped data कहते हैं।

वर्ग-अंतराल आवृत्ति
0–10 5
10–20 8
20–30 12
30–40 7

4. Grouped Data का Mean

Mean आँकड़ों का औसत मान बताता है।

Direct Method

Mean = Σfᵢxᵢ / Σfᵢ

जहाँ:
fᵢ = आवृत्ति
xᵢ = वर्ग-चिह्न

Steps

  1. Class mark xᵢ निकालें।
  2. fᵢ और xᵢ को multiply करें।
  3. Σfᵢxᵢ निकालें।
  4. Σfᵢ निकालें।
  5. Mean का formula लगाएँ।
उदाहरण:

Class intervals: 0–10, 10–20, 20–30
Frequencies: 2, 3, 5

Class marks:
5, 15, 25

Σfᵢxᵢ
= 2×5 + 3×15 + 5×25
= 180

Σfᵢ = 10

Mean = 180/10
= 18

5. Assumed Mean Method

जब class marks बड़ी हों, तो assumed mean method calculation को आसान बनाता है।

dᵢ = xᵢ − a

Mean = a + Σfᵢdᵢ / Σfᵢ

यहाँ a assumed mean है।

6. Step-Deviation Method

जब class intervals समान हों, तब step-deviation method calculation को छोटा और आसान बना सकता है।

uᵢ = (xᵢ − a) / h

Mean = a + h(Σfᵢuᵢ / Σfᵢ)

जहाँ:

  • a = assumed mean
  • h = class size
  • xᵢ = class mark

7. Median

आँकड़ों को क्रम में रखने के बाद बीच के मान को Median कहते हैं। Grouped data में इसके लिए formula का उपयोग किया जाता है।

Median = l + [(n/2 − cf) / f] × h
  • l = median class की lower boundary
  • n = total frequency
  • cf = median class से पहले की cumulative frequency
  • f = median class की frequency
  • h = class size

Median निकालने के Steps

  1. Total frequency n निकालें।
  2. n/2 निकालें।
  3. Cumulative frequency बनाएं।
  4. Median class पहचानें।
  5. Formula में values रखें।

8. Mode

जो मान सबसे अधिक बार आता है उसे Mode कहते हैं। Grouped data में highest frequency वाली class को modal class कहते हैं।

Mode = l + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × h
  • l = modal class की lower boundary
  • f₁ = modal class की frequency
  • f₀ = उससे पहले वाली class की frequency
  • f₂ = उसके बाद वाली class की frequency
  • h = class size

9. Cumulative Frequency

Frequencies को लगातार जोड़ने पर cumulative frequency प्राप्त होती है।

Class Frequency Cumulative Frequency
0–10 5 5
10–20 8 13
20–30 12 25
30–40 7 32
पहली frequency से शुरू करके सभी frequencies को क्रम से जोड़ते जाएँ।

10. Median Class

जिस class की cumulative frequency पहली बार n/2 के बराबर या उससे अधिक हो, वही median class होती है।

Median Class → First CF ≥ n/2

11. Empirical Relation

Moderately symmetrical distribution के लिए empirical relation का उपयोग किया जा सकता है।

Mode = 3 Median − 2 Mean

या

3 Median = Mode + 2 Mean
उदाहरण:

Mean = 20
Median = 22

Mode = 3(22) − 2(20)
= 66 − 40
= 26

12. Continuous Class Intervals

कभी-कभी class intervals इस प्रकार दिए होते हैं:

10–19, 20–29, 30–39

आवश्यकता होने पर इन्हें continuous intervals में बदला जा सकता है।

उदाहरण:

10–19, 20–29

को:
9.5–19.5, 19.5–29.5

में बदला जा सकता है।
