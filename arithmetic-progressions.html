📐 General Form of AP

An arithmetic progression is a sequence in which the difference between consecutive terms is constant.

a, a + d, a + 2d, a + 3d, ...

Common Difference

d = a₂ - a₁

✏️ Solved Example

Find the common difference of the AP:

5, 9, 13, 17, ...


First term: a₁ = 5

Second term: a₂ = 9

d = a₂ - a₁

d = 9 - 5

d = 4

🧮 Formula 1 – nth Term

nth Term

aₙ = a + (n - 1)d

✏️ Solved Example

Find the 10th term of the AP:

2, 5, 8, 11, ...


Here:

a = 2

d = 5 - 2 = 3

n = 10


Using the formula:

aₙ = a + (n - 1)d

a₁₀ = 2 + (10 - 1) × 3

a₁₀ = 2 + 27

a₁₀ = 29

🧮 Formula 2 – Sum of n Terms

Sum of First n Terms

Sₙ = n/2 [2a + (n - 1)d]

✏️ Solved Example

Find the sum of the first 10 terms of:

2, 5, 8, 11, ...


Here:

a = 2

d = 3

n = 10


Using the formula:

Sₙ = n/2 [2a + (n - 1)d]

S₁₀ = 10/2 [2(2) + (10 - 1)(3)]

S₁₀ = 5 [4 + 27]

S₁₀ = 5 × 31

S₁₀ = 155

🧮 Formula 3 – Sum Using Last Term

Sₙ = n/2 (a + l)

✏️ Solved Example

Find the sum of the first 10 terms of:

2, 5, 8, 11, ...


We already know:

a = 2

l = 29

n = 10


Using:

Sₙ = n/2 (a + l)

S₁₀ = 10/2 (2 + 29)

S₁₀ = 5 × 31

S₁₀ = 155

🎯 Exam Important Points

⭐ Always identify the first term (a) and common difference (d).
⭐ Remember the nth-term formula.
⭐ Learn both formulas for finding the sum of n terms.
⭐ Practice word problems based on AP.
