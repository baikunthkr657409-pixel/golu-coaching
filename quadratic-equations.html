Introduction

A quadratic equation is an equation of the form ax² + bx + c = 0, where a ≠ 0. In this chapter we learn different methods to find its roots.

1. General Form of a Quadratic Equation

The general form is:

ax² + bx + c = 0

where a ≠ 0

Here a, b and c are real numbers.

2. Roots of a Quadratic Equation

The values of x which satisfy the quadratic equation are called its roots or solutions.

Solved Example:

Find the roots of x² − 5x + 6 = 0.

x² − 5x + 6 = 0
x² − 2x − 3x + 6 = 0
x(x − 2) − 3(x − 2) = 0
(x − 2)(x − 3) = 0

Therefore:
x = 2 or x = 3

Answer: The roots are 2 and 3.

3. Solution by Factorisation

A quadratic equation can sometimes be solved by splitting the middle term and factorising the equation.

Solved Example:

Solve x² + 7x + 12 = 0.

x² + 7x + 12 = 0
x² + 3x + 4x + 12 = 0
x(x + 3) + 4(x + 3) = 0
(x + 3)(x + 4) = 0

x = −3 or x = −4

Answer: x = −3, −4

4. Quadratic Formula

For ax² + bx + c = 0, the roots are given by:

x = [-b ± √(b² − 4ac)] / 2a
Solved Example:

Solve 2x² − 5x + 2 = 0 using the quadratic formula.

a = 2, b = −5, c = 2

x = [5 ± √((-5)² − 4(2)(2))] / 4
= [5 ± √(25 − 16)] / 4
= [5 ± 3] / 4

x = 8/4 = 2
x = 2/4 = 1/2

Answer: x = 2 and x = 1/2

5. Discriminant

The discriminant tells us about the nature of the roots.

D = b² − 4ac

Case 1: D > 0

The equation has two distinct real roots.

Case 2: D = 0

The equation has two equal real roots.

Case 3: D < 0

The equation has no real roots.

6. Nature of Roots

Solved Example:

Determine the nature of roots of x² − 4x + 4 = 0.

a = 1, b = −4, c = 4

D = b² − 4ac
= (−4)² − 4(1)(4)
= 16 − 16
= 0

Answer: The equation has two equal real roots.

7. Relationship Between Roots and Coefficients

If α and β are the roots of ax² + bx + c = 0, then:

α + β = −b/a

αβ = c/a
Solved Example:

For 2x² − 7x + 3 = 0, find the sum and product of roots.

a = 2, b = −7, c = 3

α + β = −b/a
= 7/2

αβ = c/a
= 3/2

Answer: Sum = 7/2 and Product = 3/2

Important Points for Exam

  • Remember the standard form ax² + bx + c = 0.
  • Remember the quadratic formula.
  • Discriminant is D = b² − 4ac.
  • If D > 0 → two distinct real roots.
  • If D = 0 → two equal real roots.
  • If D < 0 → no real roots.
  • Write all steps clearly while solving.
